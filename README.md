# ambrosia
A sleek, myth-inspired medication management app that empowers users to track prescriptions, receive timely reminders, and maintain wellness with ease. Named after the Greek goddess of universal healing, PanaceaRx blends intuitive design with secure scheduling, dosage tracking, and refill alerts. Built for reliability, privacy, and peace of mind.

## Development

- Copy environment template: `cp .env.example .env`
- Install pre-commit hooks (recommended): `pre-commit install`
- Open a feature branch from `main`

## Security

- Never commit secrets; use `.env` locally. `.env` is gitignored.
- PRs run secret scanning (Gitleaks), dependency review, and CodeQL.
- See `SECURITY.md` for reporting and disclosure policy.
